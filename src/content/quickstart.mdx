# Quickstart

By the end of this page you will have opened a project in VS Code, run a
script from the integrated terminal, and stopped on a breakpoint.

## Prerequisites

- Node.js installed (check with `node --version`)

## Install VS Code

Download the installer for your operating system from the official VS Code
website and run it. On Windows, leave the option to add VS Code to your
PATH selected.

## Open a project folder

```bash
mkdir hello-vscode
cd hello-vscode
code .
```

If `code` isn't recognized, see [Troubleshooting](#troubleshooting).

## Create and run a script

Create a file named `hello.js`:

```javascript
const names = ["Asha", "Ravi", "Meera"];

for (const name of names) {
  const greeting = `Hello, ${name}!`;
  console.log(greeting);
}
```

Open the integrated terminal and run it:

```bash
node hello.js
```

## Debug the script

1. Click in the gutter left of the line `const greeting = ...` to set a breakpoint.
2. Press **F5** and, if prompted, choose Node.js.
3. Execution stops at the breakpoint. Inspect `name` in the **Variables** panel.
4. Press **F5** again to continue.

## Open the Command Palette

Press `Ctrl+Shift+P` (`Cmd+Shift+P` on macOS). Almost every VS Code
action is available here, so you don't need to memorize menus.

## Troubleshooting

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| `code: command not found` (macOS) | Shell command not installed | Open the Command Palette and run **Shell Command: Install 'code' command in PATH**, then restart the terminal |
| `code` not recognized (Windows) | PATH option was cleared during install | Reinstall and keep the PATH option, or add the install folder to PATH manually |
| F5 does nothing | No debuggable file active | Make sure `hello.js` is the active editor tab |
